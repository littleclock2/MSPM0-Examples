# MSPM0 G3507-V2.0

TI MSPM0G3507 V2.0 开发板例程合集，包含 LED、按键、OLED、IMU 等基础实验。

## 硬件需求

- 主控芯片：MSPM0G3507
- 显示：0.96 寸 OLED（SPI 接口）
- 传感器：ICM-45686 IMU（可选）

## 软件环境

- IDE：Keil MDK-ARM / VS Code + Keil Assistant
- SDK：TI MSPM0 SDK

## 例程列表

| 例程 | 说明 |
|------|------|
| 00_empty | 空工程模板 |
| 01_LED | LED 闪烁 |
| 02_KEY | 按键检测 |
| 03_RGB | RGB LED 控制 |
| 04_OLED | OLED 显示 |
| 05_ICM45686 | IMU 传感器读取 |
| MatlabControl | Matlab 上位机控制 |
| Template-32M | 32MHz 时钟模板 |
| Template-32M-TDC | 32MHz+TDC 模板 |
| Template-80M | 80MHz 时钟模板 |
