# MSPM0L1306开发套件例程

MSPM0L1306 开发套件基础例程，用于单片机培训与学习。

![image](./docs/img/005.png)

![image](./docs/img/004.png)

## 特性

* 无需MSPM0 SDK即可完成项目内工程的编译和运行
* 自带CMSIS-DAP调试器

## 快速上手

首先参考[使用教程-环境配置](https://pansamic.gitee.io/mspm0-devkit/#/Development_Env/Keil)按照教程安装Keil MDK软件。

下载本仓库代码，点开一个例程文件夹，进入例程文件夹下的keil文件夹，找到`XXXX.uvprojx`,双击后默认使用Keil软件打开。

用Type-C线连接电脑和开发板并按下板载开关上电，系统会弹出CMSIS-DAP的调试器信息，说明调试器连接成功。
